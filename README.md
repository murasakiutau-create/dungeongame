# 紫晶の迷宮（Amethyst Labyrinth）

Canvas API と Vanilla JS だけで作った、一人称3D視点（ウィザードリィ風）のドット絵ダンジョンRPGです。
壁・床・天井はレイキャスティングで描いていて、オートマップ付きです。
`index.html` をブラウザで開くだけで遊べます。

## 操作
| キー | 動作 |
| --- | --- |
| ↑ / ↓ | 前進 / 後退 |
| ← / → | 左 / 右を向く |
| M / Tab | 全体マップ（オートマップ） |
| Enter / Z / Space | 決定・メッセージ送り |
| Esc / X | もどる |
| I | どうぐ（バトル中も使えます・1ターン消費） |
| S | セーブ（localStorage） |

マウス・タッチでも遊べます。探索中は画面の左端・右端をタップで向きを変え、中央で前進、下のほうで後退します。右上のミニマップをタップすると全体マップが開きます。

## ゲームの流れ
- 行ったところ・見えたところはオートマップに自動で記録されます
- 各階の階段（▼マーク）をさがして下の階へ。降りるたびにオートセーブ
- 歩いているとランダムで敵と遭遇 → ターン制バトル（こうげき / ぼうぎょ / まほう / にげる）
- 敵を倒すと経験値・ゴールド・アイテム。レベルアップでHP/MP全回復＆新しい魔法を覚えます
- 床に落ちているアイテムは踏むと拾えます。歩くとHP/MPが少しずつ回復します
